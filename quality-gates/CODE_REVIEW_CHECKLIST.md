# Code Review Checklist

- [ ] Scope matches requirement; no unrelated changes.
- [ ] Correct behavior and edge cases.
- [ ] Clear responsibilities and maintainable code.
- [ ] Input validation and output encoding.
- [ ] Server-side authentication/authorization and ownership checks.
- [ ] SQL safety, data integrity, constraints, transactions, concurrency.
- [ ] N+1, pagination, query and resource efficiency.
- [ ] Error handling, logging, privacy redaction.
- [ ] Queue/event retry and idempotency behavior.
- [ ] File upload/download security.
- [ ] Dependency compatibility, license, advisory, lockfile.
- [ ] Tests meaningfully cover positive and negative paths.
- [ ] Migration, config, API compatibility, and deployment impacts.
- [ ] Documentation and ADR updates.
- [ ] No secrets or sensitive data exposed.

Record findings with severity, evidence, and actionable remediation.
