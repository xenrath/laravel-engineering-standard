# Release Checklist

- [ ] Release scope, commit/artifact, and target environment recorded.
- [ ] Acceptance criteria and required reviews complete.
- [ ] Required CI checks and tests passed.
- [ ] Security findings triaged; blockers resolved or release blocked.
- [ ] Dependency and configuration changes reviewed.
- [ ] Database migrations/backfills reviewed for compatibility and lock risk.
- [ ] Backup/recovery readiness confirmed.
- [ ] Deployment approval obtained.
- [ ] Monitoring, queue, scheduler, storage, and integrations ready.
- [ ] Smoke tests and rollback/forward recovery plan prepared.
- [ ] Post-deployment verification and communication completed.
- [ ] Release notes and project status updated.
