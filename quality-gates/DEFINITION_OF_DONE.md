# Definition of Done

A task is Done only when applicable criteria are met:

- [ ] Acceptance criteria implemented.
- [ ] Code reviewed and diff checked.
- [ ] Validation and authorization enforced server-side.
- [ ] Relevant tests executed with actual results recorded.
- [ ] Security, data integrity, and compatibility considered.
- [ ] Migrations/configuration/deployment steps documented.
- [ ] No unresolved blocker; residual risks are accepted by an owner.
- [ ] Affected documentation and status updated.
- [ ] Release/approval state recorded correctly.

Use distinct states: Implemented, Tested, Verified, Approved, Released. If some criteria are unmet, report partial completion rather than Done.
