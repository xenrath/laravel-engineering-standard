# Session Handover Workflow

## Rules
- Use verified facts only; label assumptions and unknowns.
- Record repository branch/commit and working-tree state when known.
- Separate code actually changed from proposals/snippets.
- Record exact commands and real test outcomes.
- Exclude credentials, tokens, private keys, cookies, and sensitive production/personal data.
- Link relevant Project Sources and files.

## Starting a new chat
Create a focused chat in the same Project, paste this handover, reference current sources, and verify repository state before editing. Do not assume a new chat knows every detail of prior chats.
